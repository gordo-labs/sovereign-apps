# Contributing

Use the public roadmap and architecture docs to select a focused contribution.
The local `working/` notes folder is intentionally not part of the public repo.
Before opening a pull request:

1. choose one task ID and keep the change within its scope;
2. run the task's required validation;
3. add real tests for changed protocol/runtime behavior;
4. update `STATUS.md` and the relevant public docs; and
5. avoid application-specific names, capabilities, payloads, or UI.

Use conventional commits. Security findings belong in a private GitHub security
advisory, not a public issue.
