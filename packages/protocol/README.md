# `@sovereign-apps/protocol`

Versioned, framework-neutral wire contracts for Sovereign Apps: bounded
framing, pairing/authentication envelopes, presence records and route
candidates. The package does not open sockets, discover peers, or grant trust;
desktop/mobile adapters and the application own those decisions.

The protocol is pre-alpha (`0.x`). Consumers must pin a compatible version and
review the compatibility table before exchanging messages across releases.
