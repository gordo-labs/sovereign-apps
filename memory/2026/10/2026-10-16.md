# 2026-10-16

## Contexto inicial

- Revisión y actualización de la vía de pairing React Native/Iroh del template Sovereign Apps.

## Decisiones

- Presentar el repositorio como componentes pre-alpha; no afirmar que el clone produce una app desktop↔mobile completa.
- El bridge móvil actual es outbound dialer; debe enviar un target tipado que agrupe direcciones directas + relay del mismo endpoint para dejar que Iroh seleccione ruta.
- El pairing por QR usa una referencia de un solo uso sobre el canal Iroh y vincula el grant al ID del peer autenticado.
- DB mínima, persistencia segura del grant y validación física quedan como tareas explícitas.
- El forwarder TCP 0.3 queda implementado como módulo opcional: preámbulo neutral, receptor Electron limitado a loopback y servicio `/health` disponible solo tras el grant.
- El host React Native quedó incorporado con cámara, deep link `sovereign://pair` y submódulo público del bridge fijado a 0.3.0; los binarios nativos generados no se versionan.
- A petición explícita del usuario, subir los cambios a la rama pública de trabajo, no a `main`.

## Pendiente / En progreso

- Pairing QR-to-grant conectado en el código Electron y React Native a nivel framed stream; tests de seguridad verifican grant, identidad y replay.
- `pnpm release:gates` y el test del host móvil pasan con Node 22.22.3; incluye lint, typecheck, tests, contract E2E, build Next, empaquetado e instalación externa de tarballs. La prueba de dos nodos nativos sigue opt-in/skipped. Next muestra un aviso de lockfile del workspace padre.
- El bridge npm sigue en 0.2.0; la fuente pública 0.3.0 está fijada como submódulo. El build nativo iOS no enlaza por símbolos UniFFI ausentes; falta Rustup con targets de compilación, por lo que no hay validación física ni claim de runnable.
- README raíz, guía del host, integración bridge, readiness, roadmap, status y workflow de CI actualizados. `working/` sigue ignorado/local.
- Se quitaron referencias a una app específica de los docs/código públicos; las guías ahora describen el contrato neutral y sus límites.
